# Application branding

The purple pyramid is the original Prompt to CAD logo. SVG, PNG and multi-size ICO files were restored byte-for-byte from the previous application. Keep these shared assets independent of any frontend or application version.

Qt embeds the PNG for application windows and the navigation rail. Windows embeds the ICO in the executable; source-launcher shortcuts and the installer use the same ICO. Package builds retain these assets and include them alongside the buildable source.
