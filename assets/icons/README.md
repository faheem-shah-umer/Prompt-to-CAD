# Interface icons

Uicons by [Flaticon](https://www.flaticon.com/uicons), regular rounded style, from @flaticon/flaticon-uicons 3.3.1. [Official source](https://github.com/freepik-company/flaticon-uicons).

Only the symbols used by this application are included. The SVG paths were extracted from the published WOFF outlines using its CSS codepoint mapping; glyph placement uses the font em size. Runtime rendering tints the paths for the selected theme. See LICENSE for the original Flaticon license. These assets are licensed separately from the application source.

Attribution is visible in Help → Credits and THIRD_PARTY_NOTICES.md. No icon service or network request is required at runtime.

`paperclip.svg` is an original application icon, licensed with the application source rather than the Flaticon assets.

The CAD glyphs chamfer, fillet, fit, holes, palette, parameters and thickness are original application artwork (20 px viewBox, 1.5 px strokes), licensed with the application source. They do not use Flaticon paths.
