# Public demo media

The plotter visualization is original local artwork generated by `python -m tools.create_demo` from the same synthetic component list as `tools.fixtures.plotter_definition()`. It is not a screenshot, screen recording, or live AI result. The native capture path remains available for a machine with a working graphical session. Every attempted capture uses a fresh isolated project, identity and settings directory; no personal project, chat, account, image, or CAD file is opened.

Prompt: Create a desktop 3-axis pen plotter with a work surface, frame, X rail, carriage, Z axis and pen holder. Keep the major assemblies as separate components.

Result: eight independently rendered CAD solids from the local backend, represented in the README by an animated visualization with a static PNG fallback.
